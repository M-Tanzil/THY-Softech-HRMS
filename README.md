# THY Softech HRMS

Multi-branch Human Resource Management System.

## Stack

Frontend: React, Vite, Tailwind CSS, Motion, Lucide React, Axios, React Hook Form, Zod, TanStack Table, Recharts, date-fns, Sonner.

Backend: Node.js, Express, JWT, bcrypt, Zod, Prisma.

Database: PostgreSQL.

See `docs/` for the PRD, architecture, workflow, ER diagram, database structure, and design theme.

This archive is the project scaffold. Application source files can be implemented module-by-module according to the PRD.
